# Linkmark

> 把常用入口和访问凭据，锁在一起。

Linkmark 是一款本地优先、可自托管的私人入口簿。它用一个受主密码保护的加密密钥库，集中管理网站书签、PostgreSQL / Redis 等服务入口，以及可复用的账号、密码、Token 和 API Key。

它没有账号体系、没有云端数据库、没有追踪脚本：静态服务器只负责交付应用页面，不会接触你的资料或主密码。

## 为什么选择 Linkmark

- **资料不离开设备**：所有业务资料以 KDBX4 密文存放在浏览器 IndexedDB；`localStorage` 仅保存主题偏好。
- **入口与密钥分离又可关联**：一个密钥可关联多个入口，一个入口也可关联多份密钥。服务地址与认证信息各归其位，避免把凭据散落在书签或连接字符串中。
- **真正的锁定边界**：启动、刷新、关闭页面、手动锁定或到期后，解密后的资料和解锁密钥只保留在当前页面内存中；锁定状态不会显示名称、分组或计数。
- **不依赖云也能迁移**：导出完整加密备份、恢复或合并到现有密钥库；还能以独立口令生成加密分享包，让接收方设置自己的本地主密码。
- **为日常资料管理而设计**：分组、标签、搜索、置顶、手动排序、回收站和响应式界面，让个人书签与基础设施资料保持清晰。
- **离线可用**：作为纯静态 PWA 发布，可安装并离线启动；不依赖第三方 CDN、分析 SDK 或远程 favicon 抓取。

## 功能一览

| 能力 | 说明 |
| --- | --- |
| 网站书签 | 保存并在浏览器打开 `http` / `https` 网站入口。 |
| 服务入口 | 为 PostgreSQL、Redis 和通用服务保存非敏感端点与配置；Linkmark 不会连接、测试或管理这些服务。 |
| 加密密钥库 | 用主密码创建并解锁唯一的本地 KDBX4 密钥库。 |
| 密钥管理 | 保存账号、密码、API Key、Token、备注和自定义字段；支持显示、复制和关联复用。 |
| 组织与检索 | 单层分组、跨入口标签、置顶、手动排序，以及仅在解锁期间可用的本地搜索。 |
| 可恢复删除 | 删除的入口和密钥进入回收站，默认保留 30 天，可恢复或永久清理。 |
| 加密迁移 | 支持版本化完整备份的导出、预览恢复与合并；支持独立口令的分享包。 |

## 快速开始

### 在线使用与部署

Linkmark 是纯前端应用。将构建产物部署到任意 HTTPS 静态托管服务即可；无需数据库、账户服务或应用后端。

> 请使用 HTTPS 部署，并为自己的重要资料保留一份加密备份。

### 本地开发

要求：Node.js（建议使用当前 LTS 版本）和 npm。

```bash
npm install
npm run dev
```

随后打开终端显示的本地地址，创建一个密钥库并设置主密码。

### 生产构建

```bash
npm run build
```

将生成的 `dist/` 目录作为静态文件发布。部署时应确保所有路由和资源均从同一可信来源加载，并配置合适的 Content Security Policy。

## 使用方式

1. 首次打开时，设置主密码以创建密钥库；主密码无法找回。
2. 新建入口，选择网站、PostgreSQL、Redis 或通用类型。
3. 将服务地址、端口等非敏感信息放在入口中；将账号、密码、Token 等认证资料保存为密钥并关联。
4. 用分组、标签和搜索整理资料；密钥可以在多个入口间复用。
5. 定期从“导出备份”保存一份加密包。换设备时，可选择恢复替换或合并导入。

## 安全与隐私

Linkmark 的安全目标是让静态托管方和浏览器持久化存储无法直接读取你的资料。

- 密钥库采用 KDBX4 格式，使用 Argon2id 派生保护；应用固定使用 64 MiB 内存、3 次迭代、并行度 1 的 KDF 参数。
- 主密码、派生密钥和解密资料不会被持久化，且不会建立入口或密钥的明文搜索索引。
- 完整备份和分享包只携带加密后的密钥库，不暴露入口、分组、标签或密钥的可读元数据。
- 导入会先解密预览，并限制 KDF 资源参数和数据大小；失败不会改写本地资料。
- 密钥值默认隐藏，查看和复制均需用户明确操作。

这不是对已失陷环境的防护：恶意浏览器扩展、XSS、被接管的浏览器配置文件或设备仍可能读取解锁期间的数据。Linkmark 也不提供主密码找回、跨设备自动同步、网页自动填充或远程连接服务的功能。

## 数据与可移植性

所有资料位于一个本地密钥库中：

```text
浏览器 IndexedDB
└── Linkmark KDBX4 密文
    ├── 入口
    ├── 密钥
    ├── 回收站
    └── 应用元数据（分组、标签等）
```

- **备份**：使用当前主密码保护，适合自己留存和恢复。
- **合并**：同时解锁备份与当前密钥库，导入记录会使用新 ID，避免静默覆盖。
- **分享**：用独立分享口令重新加密；接收方导入后设置自己的本地主密码，分享口令不会成为其长期主密码。

## 技术栈

- React 19 + TypeScript + Vite
- KDBX4 / `kdbxweb` 密钥库
- Argon2id（本地 WASM Worker）
- IndexedDB / Dexie
- PWA Service Worker
- Vitest + Playwright

## 项目边界

Linkmark 是“访问资料管理器”，不是密码管理平台或运维客户端。它刻意不包含：账户系统、云同步、外部数据导入、TOTP、附件、浏览器扩展、自动填充、远程网页标题 / 图标抓取、第三方分析，以及数据库或缓存连接测试。

这些取舍让应用保持轻量、可离线、易于自托管，并将隐私边界收敛在你自己的浏览器和设备中。
